Connect your app.

Send structured logs from your app’s server to RootCause over HTTPS. You’ll need a server or log forwarder that can keep a private API key secret.

1. Create an app and get its key

Sign in to RootCause, open your workspace, and choose Add an app. Give it a name, then copy the private API key when it appears. RootCause shows the key once; if you lose it, rotate the key in your workspace.

Sign in to your workspace Create an account

2. Save the key on your server

In your hosting provider’s server-side environment or secrets settings, add:

ROOTCAUSE_URL=https://rootcause-vzts.onrender.com
ROOTCAUSE_API_KEY=your_private_app_key

Use the key only on a server or trusted log forwarder. Never put it in browser JavaScript, a public repository, or a mobile app. If your site has no backend or secure place for secrets, don’t connect it directly: use the free explainer to paste one log at a time, or add a backend/log forwarder first.

3. Send a test log

From your server, send a request to https://rootcause-vzts.onrender.com/v1/logs with the key as a Bearer token. For Node.js:

await fetch(`${process.env.ROOTCAUSE_URL}/v1/logs`, {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.ROOTCAUSE_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    logs: [{
      level: "ERROR",
      service: "checkout",
      message: "Database connection timed out"
    }]
  })
});

A successful request returns 202 Accepted. Your workspace will show the app as connected after it receives the first log. The API accepts structured logs; it does not automatically read logs from your app until you configure a sender.

Monitoring status: RootCause can receive logs, but continuous 24/7 monitoring and alert delivery are not live. Keep your existing monitor for critical systems.
