● ● ●   ROOTCAUSE / STATIC EXAMPLE ILLUSTRATIVE LOG
2026-10-19T09:41:22Z ERROR checkout-api
connect ECONNREFUSED 127.0.0.1:5432
GET /api/users/42 · HTTP 500 · 3.02s

Checkout cannot connect to Postgres.

The API tried to open a database connection, but nothing accepted it at 127.0.0.1:5432. This often means the database is stopped or the app has the wrong host or port.

What to check
  • Confirm Postgres is running and listening on port 5432.
  • Check the database host and port in the app’s environment settings.
  • If the app runs in a container, use the database service name instead of 127.0.0.1.
