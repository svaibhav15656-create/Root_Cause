Log sample

2026-10-24T09:42:18.392Z ERROR [checkout-api] request_id=8f3a2c1d
POST /api/orders 500 duration=30.02s
SequelizeConnectionAcquireTimeoutError: Operation timeout
    at ConnectionManager.getConnection (node_modules/sequelize/lib/dialects/abstract/connection-manager.js:206:15)
    at process.processTicksAndRejections (node:internal/process/task_queues:95:5)
Caused by: Error: connect ETIMEDOUT 10.0.4.18:5432
    at TCPConnectWrap.afterConnect [as oncomplete] (node:net:1549:16)
Retry attempts: 3 | pool max: 10 | active: 10 | waiting: 27

What likely happened

The checkout service could not get a database connection before its 30-second timeout. The log shows all 10 pool connections were busy, 27 requests were waiting, and a connection attempt to the database timed out. This points to database connectivity or capacity pressure; it does not by itself prove which one.

How to investigate and fix it

  1. Check database health and network connectivity to 10.0.4.18:5432 at the incident time. Confirm the address, firewall rules, and database availability.
  2. Inspect active queries and connection-pool usage. Find slow queries or transactions holding connections, and ensure connections are released on both success and error paths.
  3. Compare incoming request volume, worker count, and database connection limits. If increasing the pool, first verify the database can handle the combined connections from every app instance.
  4. Retry the failed request only if order creation is idempotent or protected by an idempotency key, to avoid duplicate orders.

This is an example explanation. Confirm the cause using your service metrics and nearby logs before changing production settings.

Connect an app
in three steps.

Sign in, create an app to get its private API key, then send structured logs to RootCause over HTTPS.

01

Sign in to your workspace

Log in or create an account, then open your workspace and choose Add an app.

02

Create an app and copy its key

RootCause displays the private API key once. Save it as ROOTCAUSE_API_KEY in a server-side environment variable or secret manager.

03

Configure your log sender

Send structured JSON to https://rootcause-vzts.onrender.com/v1/logs with the key as a Bearer token. Keep the key out of browser code and source control.
